# HostelEase — Student Hostel Management System

A modern, university-style hostel management website built with pure HTML, CSS, and JavaScript.

## Project Structure

```
HostelEase/
├── index.html              ← Main homepage
├── css/
│   └── style.css           ← All styles (university theme)
├── js/
│   └── main.js             ← JavaScript (scroll reveal, modal, counters)
├── pages/
│   ├── rooms.html          ← Full room directory with filter
│   └── dashboard.html      ← Student dashboard
└── README.md
```

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Homepage: Hero, About, Rooms, Amenities, Pricing, Contact |
| `pages/rooms.html` | Room directory with Boys/Girls hostel listing |
| `pages/dashboard.html` | Student portal: room info, fee history, notices |

## Features

- ✅ University-style design (navy + red institutional palette)
- ✅ Sticky top navigation with dropdowns
- ✅ Notice band with dismissal
- ✅ Quick room enquiry form in hero
- ✅ Animated scroll-reveal sections
- ✅ Room type tabs (Super Deluxe / Deluxe / Standard)
- ✅ Room directory with availability badges
- ✅ Transparent pricing cards
- ✅ Contact form with submission feedback
- ✅ Sign In / Register modal
- ✅ Student dashboard with sidebar
- ✅ Fee payment history
- ✅ Hostel notices board
- ✅ Quick services panel
- ✅ Fully responsive

## Design System

**Colors**
- Navy: `#1a2a4a` (primary)
- Red: `#c0392b` (accent/CTA)
- Off-white: `#f4f6f9` (backgrounds)
- Gold: `#e8a020` (notices/highlights)

**Fonts**
- Headings: Merriweather (serif) — institutional feel
- Body: Source Sans 3 — clean and readable

## How to Use

1. Open `index.html` in any browser — no build tools required
2. All assets are loaded from Google Fonts CDN
3. To connect a backend, update form `action` attributes and replace `onsubmit` handlers in JS
